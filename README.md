# Shweta's Makeover — Premium Portfolio Website

An 8-page static website concept designed as a salon/beauty-business portfolio project.

## Pages
1. Home
2. About
3. Services
4. Hair
5. Beauty & Skin
6. Nails & Body
7. Makeup & Bridal
8. Contact & Booking

## Visual direction
- Classic, expensive, editorial salon aesthetic
- Warm ivory / espresso / muted beige palette
- Cormorant Garamond + Montserrat typography
- Large negative space and premium navigation
- Responsive mobile navigation
- Separate service pages rather than one overloaded page

## Important pricing note
The haircut prices supplied by the client are retained:
- Straight/basic haircut: ₹180
- Advanced haircut: ₹350
- Split ends: ₹250
- Bangs: ₹80

Other prices shown on the Hair page are proposed portfolio prices only and should be confirmed with the business before publication.

## Launch checklist
- Replace the abstract hero artwork with the salon's real professional photography.
- Add the actual phone/WhatsApp number.
- Connect the booking form to WhatsApp, Formspree, a CRM, or the client's preferred booking system.
- Confirm every service name and price with the client.
- Add Google Maps embed and verified social media links.
